# PingPD landing page

Public marketing/landing page for **PingPD** — a Hong Kong Parkinson's Disease daily-logging + ping-pong rehab app (research MVP).

🔗 **Live site:** https://nathan1658.github.io/pingpd-landing/

This repo holds only the static landing page (`index.html`). The Flutter application source lives in a separate private repository.

## Stack

- Single static HTML file
- Tailwind via CDN
- Google Fonts: Noto Serif HK · Fraunces · Noto Sans HK
- Photographs from Unsplash (with loremflickr fallbacks)

## Local preview

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
