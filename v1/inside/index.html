臨床量表

UPDRS-8 · 八項每日評估的核心

UPDRS 是柏金遜症臨床上最通用的評估量表，惟完整版近五十項，只適合由醫護於診所內執行。UPDRS-8 抽取當中最容易於日內起伏的八項，保留臨床語義，讓病患於家中每日自評也能沿用相同刻度。

震顫

靜止或活動時手、腳或頭部的不自主顫動。

0 1 2 3 4

僵硬

肌肉緊繃、關節活動阻力增加。

0 1 2 3 4

動作遲緩

起立、行走、日常動作變慢或難以啟動。

0 1 2 3 4

姿勢

站立或行走時身體的穩定度與平衡。

0 1 2 3 4

步態

起步、轉身、停步時的流暢度。

0 1 2 3 4

書寫

字跡大小、力度、清晰度的變化。

0 1 2 3 4

情緒

抑鬱、焦慮、動力低落等非運動症狀。

0 1 2 3 4

睡眠

一日流程

一天之中，在四個關鍵時刻提醒你

症狀的變化並非平均分佈，PingPD 於一日四個節點輕輕提示，讓記錄自然融入晨起、服藥、活動與入睡的節奏之中。

晨起

3

4

睡前

總結今日表現，計劃明日節奏。

無障礙設計

為長者度身設計的介面

55 至 80 歲的使用者，往往同時面對視力退化、手部顫抖與反應稍慢。PingPD 的每一個元件，皆以此為前提設計。

準則

48dp 最小觸控區

所有按鈕與滑桿均不少於 48dp，顫抖的手指也能準確點擊。

準則

高對比配色

所有文字與背景符合 WCAG AA 對比度標準，即使於戶外陽光下亦能清晰閱讀。

準則

大字與 1.6 行距

中文字體不少於 16sp，行距 1.6 確保長篇易讀，減輕眼部負擔。

準則

可關閉動畫

尊重系統的「減少動畫」偏好，不打擾認知負荷高的時刻。

覆診匯出

覆診前一頁，總結過去一季

覆診時間有限，醫生最需要的不是數據堆疊，而是重點清晰的一頁摘要。

報告內容

一頁式 PDF 以單一版面總結你過去一季的 UPDRS-8 趨勢、服藥時序與重點備註。所有生成於裝置本地完成，無須上載雲端。病患可自選日期範圍，亦可選擇匿名化處理，再以電郵或紙本交予主診醫生。
